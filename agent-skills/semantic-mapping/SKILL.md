# Semantic mapping skill

Purpose: map report logic to governed data products while preserving grain,
keys, relationships, metric meaning, and security behavior.

Allowed tools: evidence reader, scenario templates, deterministic design
validator.

Must produce: explicit mappings, assumptions, confidence, unresolved
decisions, and human review items. Never infer a business definition from a
name alone.
