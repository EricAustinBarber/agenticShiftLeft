# Domain-specific demo fixture

This directory contains the Scanman proof-of-concept material used to exercise
the generic Agentic Shift Left engine. It is regression/demo evidence only and
is not an application default, supported-domain assumption, or production
configuration.

Contents:

- `config/` — demo scenario and rewrite manifests;
- `templates/` — demo Databricks contracts, notebooks, SQL, job, and PBIT query templates;
- `docs/` — demo migration mapping and approved comparison evidence;
- `artifacts/` — demo inventory output.
